## AI Agent Auto Trading System

This repository contains a comprehensive AI-powered automated trading system implemented in Python.

### Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run the example
python example_trading.py

# Run tests
python -m trading_agent.tests.test_agent
```

### Features

- **Multiple Trading Strategies**: Trend Following, Mean Reversion, and Momentum
- **AI-Powered Predictions**: Statistical analysis for better trade decisions
- **Risk Management**: Stop-loss, take-profit, and drawdown protection
- **Portfolio Management**: Real-time tracking of positions and P&L
- **Technical Indicators**: MA, EMA, RSI, Bollinger Bands, MACD
- **Backtesting**: Simulated market data for strategy testing
